This is a curated snapshot of relevant skill Markdown folders, not a clone of every source repository. The UI/UX Pro Max Markdown instructions and references are included, but its non-Markdown Python scripts and searchable datasets are not. Consult/install the upstream package when those capabilities are needed. Check each source repository's current license before redistribution; this repository links to the upstream sources rather than relicensing them.
