# Skill: UI/UX Design Specification

## Design workflow
1. Read the approved brief and identify primary users and core flows.
2. Inspect existing visual language before proposing changes.
3. Define information architecture and screen inventory.
4. Specify layout, spacing, typography, color, component behavior, and responsive rules.
5. Specify empty, loading, error, disabled, pressed, focused, and success states as relevant.
6. Include accessibility: semantics, focus order, contrast, touch target, text scaling.
7. Write acceptance criteria that Programmer and Reviewer can verify.

## Required component fields
- Name and purpose
- Placement and hierarchy
- Dimensions/units
- Content and typography
- Visual tokens
- Interaction/state behavior
- Accessibility semantics
- Implementation notes
- Acceptance criteria

## Avoid
- Subjective-only descriptions.
- Unspecified units.
- Unspecified edge states.
- Designs that depend on assets not included in the asset inventory.
